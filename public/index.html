TP91 Telegram Notifier API

Tạo API Key riêng trong 30 giây và gắn vào website của bạn để tự động báo đơn hàng, form liên hệ về Telegram cá nhân hoặc nhóm — không cần tạo thêm database hay server riêng.

1. Tạo API Key của riêng bạn

Token Bot của bạn được mã hóa bằng AES-256-GCM thành API Key. Server không lưu trữ token ra ổ đĩa hay database.

  1. Mở Telegram, nhắn @BotFather → gõ /newbot để lấy Bot Token.
  2. Mở chat với con bot vừa tạo và bấm nút Start ít nhất 1 lần.
  3. Nhắn @userinfobot để lấy dãy số Chat ID của bạn.
Để trống nếu bạn gọi từ Backend (Next.js, Node.js, PHP, n8n).

2. Gắn vào dự án của bạn

Chỉ cần dán API Key vào biến môi trường và gọi endpoint POST /api/notify.

Lưu ý bảo mật: Khi dùng trên Next.js/Node.js/PHP, hãy lưu API Key ở phía server (.env.local hoặc Vercel Environment Variables, không dùng tiền tố NEXT_PUBLIC_). Nếu dùng cho HTML tĩnh không có backend, hãy điền ô Khóa theo Domain ở cột bên trái.
